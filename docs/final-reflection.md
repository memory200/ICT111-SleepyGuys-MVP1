# Final Team Reflection (Lab 14)

**Group Name:** SleepyGuys  
**Project:** Smart Campus Lost and Found System  

---

## 1. Key Accomplishments & Technical Growth
* **End-to-End MVP Delivery:** Successfully built, tested, and finalized a working web-based Lost and Found portal addressing real campus pain points.
* **Traceability & Engineering Discipline:** Mapped all 12 Functional Requirements (`FR-01` to `FR-12`) directly to prototype code, user stories, and documentation artifacts.
* **User-Centric Design:** Validated user flows through testing sessions, achieving an 82% successful recovery rate during simulated trials.

---

## 2. Key Challenges & Lessons Learned
* **State Management:** Simulating persistence without a dedicated database required careful structuring of browser `localStorage` to prevent state loss on page reloads.
* **Cross-Module Navigation:** Ensuring seamless transitions between `landing-page/index.html` and `prototype/index.html` highlighted the importance of clear CTA design and relative path management.
* **Collaboration & Git Workflow:** Learned effective repository management, branch syncing, and traceability documentation within a unified team environment[cite: 1].

## 3. Future Outlook
If extended into a full commercial release, the team would focus on integrating campus Single Sign-On (SSO) for security and implementing AI-driven visual matching for uploaded lost item photos[cite: 1].
