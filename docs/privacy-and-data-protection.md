# Privacy and Data Protection Policy

## 1. Data Minimization
We only collect necessary fields for reporting and searching lost items:
- `Test_User_ID`, `User_Role`, `Main_Task`, `Time_Seconds`, `Feedback_Score`
- Sensitive personal identification numbers or private passwords are **never** collected.

## 2. Data Storage & Access
- Test dataset is stored securely in `/data/validation-results.csv`.
- Admin-level actions (updating status to 'Claimed') are restricted to Security Staff (`FR-3.2`).
