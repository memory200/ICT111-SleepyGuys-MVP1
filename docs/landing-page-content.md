# Landing Page Content

## Project Title
Smart Campus Lost and Found System (SleepyGuys Project)

## Target User
Campus undergraduate/graduate students, faculty staff, and campus security/administrative personnel.

## Headline
Find and Report Lost Campus Belongings Effortlessly.

## Subheadline
A centralized digital portal designed to streamline campus lost-and-found management with real-time status tracking and smart filters.

## Problem Statement
Students frequently lose valuable items (e.g., student IDs, electronics, keys) across campus. Current retrieval relies on fragmented Telegram/Messenger group chats, leading to lost posts, privacy risks, and low recovery rates.

## Solution Description
Our platform provides a single interactive portal where students can quickly report missing or found items, filter records by campus zone, track resolution status, and contact administrators securely.

## Key Features

| Feature | Requirement ID | User Value | Prototype Screen/Module |
| --- | --- | --- | --- |
| Report Item Form | FR-03 | Easily submit lost or found items with photos and descriptions | Input Form Module |
| Search & Filter Records | FR-06 | Filter items dynamically by category, status, and campus zone | Record List Screen |
| Admin Status Updates | FR-08 | Track progress as items change from 'Pending' to 'Claimed' | Admin View & Detail Modal |
| Startup Metrics Dashboard | FR-12 | View overall campus activity summary and resolution stats | Analytics Dashboard |

## Benefits
- **Save Time:** No need to scroll through hundreds of chat messages to find missing items.
- **Real-Time Visibility:** Track whether an item has been verified, pending, or returned.
- **Privacy Protection:** Personal student contact information is protected and managed through controlled channels.

## Call-to-Action
- **Primary:** Try Demo Prototype
- **Secondary:** View Metrics Dashboard

## Responsible Data Message
We are committed to data privacy. No personal identification numbers or sensitive confidential data are publicly exposed. Information submitted via forms is used strictly for item ownership verification purposes.
